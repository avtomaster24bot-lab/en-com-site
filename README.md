# Сайт сервисного центра: ремонт телефонов, ноутбуков и компьютеров

🌐 https://avtomaster24bot-lab.github.io/en-com-site/

Продающий одностраничный сайт + **лента постов**, которую каждый день пополняет бот
`en.com-agnes-video-bot` (приватный репозиторий): вертикальный ролик с озвучкой и тихой фоновой музыкой,
карточки-слайды и текст. Тот же пост одновременно уходит альбомом в Telegram-канал со ссылкой сюда.

## Что на сайте
- Первый экран с призывом записаться на диагностику и свежим роликом из ленты.
- «Что случилось с техникой?» — выбор симптома → подходящие ролики из ленты + кнопка записи.
- Услуги, этапы работы, цены, вопросы и ответы, контакты.
- Лента с фильтром по рубрикам; страница поста: видео, карусель карточек, текст, «Коротко», «Важно знать», кнопки записи и «поделиться».
- Мобильная версия с закреплённой кнопкой «Записаться».

## Что заполнить (site.json)
Все реальные данные бизнеса лежат в `site.json`. Пока поле пустое, на сайте показывается «уточняется»:
`phone`, `whatsapp`, `telegram_contact` (для записи), `telegram_channel` (канал с постами), `address`, `hours`, `map_url`, `city`,
цены в `prices[].price` и `services[].price`. Название бренда — `brand`.
Как только появится WhatsApp/Telegram/телефон, все кнопки «Записаться» начнут вести прямо туда.

## Как появляются посты
Бот кладёт каждый пост в `posts/<дата>-<тема>/` (`video.mp4`, `s1..s4.jpg`, `post.json`) и добавляет запись в `data/posts.json`.
Доступ на запись — через deploy key этого репозитория (секрет `SITE_DEPLOY_KEY` в репозитории бота).
Чтобы репозиторий не разрастался, видео хранится только у последних 60 постов (у старых остаются карточки и текст).

Сайт — обычные `index.html`, `app.js`, `style.css`, без сборки. GitHub Pages: ветка `main`, корень.
